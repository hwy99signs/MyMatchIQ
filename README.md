# MyMatchIQ

**Clarity Before Connection.**

This is the official permanent code repository for MyMatchIQ.

## Locked product direction

MyMatchIQ is a privacy-first compatibility intelligence platform, not a traditional dating app. Preserve the approved MyMatchIQ appearance, branding, layout, logo, colors, and core UX. Do not introduce traditional chat/DM, swipe/discovery dating behavior, dating-game concepts, or speculative product changes.

Approved core product includes:
- Compatibility Passport
- Structured compatibility assessment
- Free / Premier / Elite tiers
- Single Scan and Dual Scan
- Mutual-consent rules
- Compatibility results
- Verification / Verified badge
- User-controlled compatibility sharing
- One2OneLove handoff where applicable
- Existing multilingual, legal, help, notification, privacy, and safety framework

## Permanent architecture

- **Code:** GitHub (`hwy99signs/MyMatchIQ`)
- **Database/backend:** existing Neon project `MyMatchIQ`
- **Hosting/deployment:** Cloudflare
- **Final architecture does not use Supabase or Vercel.**

## Migration rule

Restore and consolidate approved source first. Backend and deployment work must remain visually non-invasive: no redesign and no visual changes simply to accommodate infrastructure.
